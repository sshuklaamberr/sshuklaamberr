### 🎓 College Placement Management System
**`The project that proves I can build real-world applications`**

</div>

> A full-stack platform that digitizes and streamlines the entire college placement pipeline — from student registration to final offer letter tracking.

```
🏛️ Architecture: MVC Pattern
🔐 Auth: Role-based JWT Authentication
🗄️ Database: MongoDB with Mongoose ODM
🌐 API: RESTful with Express.js
```

**✨ Key Highlights:**

- 🔑 **3-tier Role System** — Admin / Student / Company with granular access control
- 📅 **Drive Scheduler** — Create & manage placement drives with deadline tracking
- 📊 **Dashboard Analytics** — Real-time placement statistics & reports
- 🔒 **Secure APIs** — Input validation, error handling & protected routes
- 📱 **Responsive UI** — Works seamlessly on all devices
